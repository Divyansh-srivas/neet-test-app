# TestPrep Pro — NEET Mock Test Platform

## Features
- PDF upload → AI extracts all questions (Allen, Aakash, NTA, FIITJEE etc.)
- 3-hour timer with auto-submit
- Physics / Chemistry / Biology separate analysis
- Bookmark wrong questions for revision
- Full profile scorecard + subject-wise averages
- Score trend charts across all tests

## Setup

### 1. Install dependencies
```bash
npm install
```

### 2. Run locally
```bash
npm run dev
```

### 3. Deploy to Vercel
1. Push this folder to GitHub
2. Go to vercel.com → New Project → Import from GitHub
3. Click Deploy — done!

## Getting Gemini API Key (Free)
1. Visit https://aistudio.google.com
2. Sign in with Google
3. Click "Get API Key" → "Create API Key"
4. Paste in the app's Settings page

## Tech Stack
- React 18 + Vite
- Recharts (charts)
- Google Gemini API (PDF extraction)
- LocalStorage (all data stored in browser)
- Vercel (hosting)
